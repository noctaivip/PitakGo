Файлы:
- privacy.html — Политика конфиденциальности
- terms.html — Условия использования

ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ:
1. Замените во всех файлах [УКАЖИТЕ РАБОЧИЙ EMAIL] на реальный рабочий адрес PitakGo.
2. Проверьте описание данных и функций по фактической версии приложения, включая все SDK и разрешения.
3. Проверьте, что запрос на удаление аккаунта/данных действительно принимается и обрабатывается.
4. Это шаблоны для подготовки публикации, а не юридическое заключение.

РАЗМЕЩЕНИЕ:
Положите privacy.html и terms.html в ту же публичную папку сайта, где находится index.html.
После деплоя ссылки будут:
https://pitakgo.pages.dev/privacy.html
https://pitakgo.pages.dev/terms.html

ССЫЛКИ В ГЛАВНОМ МЕНЮ/ФУТЕРЕ:
Добавьте в существующий футер index.html:
<a href="/privacy.html">Политика конфиденциальности</a>
<a href="/terms.html">Условия использования</a>

Не заменяйте весь index.html этим фрагментом. Чтобы подготовить точный готовый index.html, нужен текущий файл index.html из проекта.
