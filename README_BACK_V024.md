Пятак Go v0.24 — системная кнопка «Назад».

- Android: @capacitor/app backButton перехватывает системную кнопку и использует стек навигации приложения.
- iOS/PWA: история браузера и видимая кнопка «‹» в шапке, также браузерный жест возврата там, где его поддерживает ОС.
- В истории: основные вкладки, вход/регистрация, сервисы, форма услуги и «Мои объявления».
- На главном экране Back не завершает приложение.
- Для установки новой нативной зависимости требуется npm install и npx cap sync android.
- Не тестировалось на физических Android/iOS устройствах.
