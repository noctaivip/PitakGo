Пятак Go v0.22 — редизайн раздела «Сервисы».

1. Главная витрина: четыре большие карточки действий.
2. Каждая услуга открывает отдельную двухэтапную форму.
3. Лента объявлений: фильтры по услуге, поиск по городам, кнопка отклика.
4. Мои объявления: просмотр откликов и завершение заявки.
5. Гостевой режим: красивая витрина без принудительной регистрации.
6. Существующие таблицы community_posts и community_offers в Supabase используются без миграций.
7. Живой пятак показывает данные статуса готовности, а не фактическую GPS-очередь.

Ограничения: реальный чат, передача посылок по коду и онлайн-оплата не реализованы.
Проверены синтаксис JavaScript и целостность архива, не выполнен сквозной тест на Android.
