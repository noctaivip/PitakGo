Пятак Go v0.27. Исправление наложения Android status/navigation bars. Основа v0.25. Новая команда: npm install; npx cap sync android; powershell -ExecutionPolicy Bypass -File .\fix-android-safe-areas.ps1; npx cap open android. Скрипт точечно добавляет native WindowInsets listener в MainActivity.java, чтобы WebView был ограничен реальными размерами системных панелей. Не меняет Supabase и логику сервисов, бронирования, регистрации. Если MainActivity имеет существующий onCreate, скрипт прекращает работу во избежание порчи. Важно: старый скрипт apply-system-bars.ps1 больше НЕ использовать. Android сборка и физическое устройство не проверены.
