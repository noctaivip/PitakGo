# PitakGo 0.14 — онлайн-логика

- Сохранена общая база Supabase и безопасные RPC бронирований.
- При обновлении статусов брони показывается уведомление внутри открытого онлайн-экрана.
- По завершении отдыха приложение напоминает подтвердить выход на линию при открытии/возвращении в приложение.
- При возврате на экран выполняется обновление профиля и бронирований.
- Не реализованы фоновые push-уведомления и геофенсинг при закрытом приложении.
- Для полноценной проверки нужны два независимых аккаунта и два телефона.
- Сохранён существующий локальный демонстрационный режим отдельно от онлайн-режима.
