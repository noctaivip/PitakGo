Пятак Go v0.29 — двусторонняя связь через Supabase.

Сервисы → Сообщения и предложения: входящие и исходящие отклики. Владелец объявления может принять или отклонить предложение, автор предложения может отозвать ожидающее. Для каждого отклика отдельный приватный чат, доступный двум участникам. Состояния и сообщения сохраняются в базе; проверка каждые 12 секунд, уведомление внутри приложения при новых предложениях, изменениях статуса, входящих сообщениях. Поездки на конкретных рейсах сохраняют отдельную систему бронирования мест с подтверждением/отклонением и уведомлениями. Согласование объявления НЕ означает автоматическую бронь конкретного места и НЕ переводит деньги.
