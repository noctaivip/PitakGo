PitakGo v0.20 — 4 направления: водитель едет по маршруту без привязки к пятаку; пассажир ищет попутку; передача посылки; покупка и доставка товаров по запросу. Реальные объявления и отклики синхронизируются через Supabase. Отклики доступны только автору объявления и отправителю. Бесплатная публикация. Вкладка «Сервисы» включает «Живой пятак» — число водителей в статусе «готов» по стоянкам, без обещаний GPS-подтверждённой очереди. Нет встроенной оплаты, гарантии доставки, полноценного чата, рейтингов и проверки личности; пока это MVP объявлений и откликов. Изменения базы данных применены к Supabase проекту PitakGo.
