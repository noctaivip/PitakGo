Пятак Go v0.30 — согласованные поездки и удобные переговоры

Основа: v0.29. Существующие SQL таблицы, RPC и права доступа не изменялись.

- В «Поездках» отдельная секция согласованных поездок по пути из сервиса «Еду по пути».
- Участники открывают личную переписку прямо из этой секции.
- Статусы предложений выделены цветом и объясняются человеческим языком.
- В чате появились быстрые шаблоны «Время?», «Место встречи?», «Цена?», Ctrl+Enter.
- Двойное нажатие «Принять» больше не отправляет параллельные решения.
- Подтверждённое предложение НЕ равно брони конкретного сиденья: это явно указано.
- Изменения ограничены online.js и online.html, остальная функциональность не переписывалась.

Ограничения: подтверждение конкретного сиденья по-прежнему происходит через обычный рейс. Push в закрытом приложении и полноценное сквозное тестирование на двух телефонах пока не реализованы.
